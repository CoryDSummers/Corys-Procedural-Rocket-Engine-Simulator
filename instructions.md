We are going to create a tool to create custom rocket engines for ksp realism overhaul. You can find any information you need on the mod on it's github. The plan is to create a simplied simulation of a rocket engine. Look at how children of a dead earth did their custom engines. I'm thinking of something simular. Should be able choose how different components work together. I.e. Turbopump design, chamber pressure, combustion cycle, engine bell shape and size. We want to be able visionally see the a basic outline of the design in a python window and be able to adjust values on the fly. You can use CUDA for simulations if need to improve speed. Materals and such can be a dropdown menu. In the future we will be creating a procedurally generated basic model for these but that will be in the future. The output for right now should be a config file and the model should be able to be choosen from the realism overhaul known engine models.
