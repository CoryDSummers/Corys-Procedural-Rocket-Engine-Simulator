Turbine-exhaust HARDWARE (2026-09-24, follow-up to ..._turbine_exhaust_before_after.txt)
=======================================================================================
Before = HEAD bd4fcf7, after = this change. Both were computed in the same Python environment
(python 3.12, numpy 2.4.6, scipy 1.17.1, cloud container) with a git worktree of HEAD.

This change is geometry and mass only; no performance number moves (Isp, thrust and mdot are
identical in every file). Every open-cycle design now carries:
- its exhaust termination (injection manifold torus / aspirator shroud + inlet collar /
  overboard exhaust nozzle), in Haynes 230 standing in for Hastelloy C;
- a default exhaust duct: an orthogonal route from the termination to the turbine's new exhaust
  port, massed like any plumbing run, flagged implicit, and drawn by the 3D preview;
- the optional heat-exchanger can.
All of it is added to the dry mass. Closed-cycle files change only by the new, empty result keys.
