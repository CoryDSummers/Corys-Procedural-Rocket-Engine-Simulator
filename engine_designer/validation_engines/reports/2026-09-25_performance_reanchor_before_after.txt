P1 performance re-anchor: Isp on the equilibrium tables (2026-09-25)
====================================================================
What changed (engine_designer/physics/combustion.py, design/combustion_stage.py):
- Bipropellant chamber state + ideal performance now come from the baked Cantera
  shifting-equilibrium tables at the actual (MR, Pc): Tc, M, frozen chamber gamma, ideal c*,
  ideal vacuum CF(eps) = Isp_vac x g0 / c* (eps 2-250), exit pressure pe/pc(eps). The old
  hand table (_TABLES: Tc/gamma/M per MR, no Pc axis, "effective" LOX/LH2 gamma/M) now only
  serves the monopropellants (Hydrazine, H2O2), which have no equilibrium table.
- Efficiency split: DEFAULT_ETA_CSTAR = 0.975 for every bipropellant (a real combustion
  efficiency, [Huzel 4.2] ~0.975, inside [Sutton 5.5]'s 0.96-0.99); new ETA_CF per pair = the
  nozzle loss (kinetics + boundary layer + residual), reverse-solved on each pair's SPOT_CHECKS
  anchor: RP-1 0.9358 (RD-111), LH2 0.9826 (RL10A-3-3), CH4 0.9588 (Raptor-2), MMH 0.9088
  (Aestus), A-50 0.9518 (AJ10-137). One number per pair ("option A") - the per-engine residuals
  below are its honest spread.
- Gammas split: s.gamma = the one-gamma exponent that reproduces the table's exit pressure at
  the design eps (nozzle-profile relations: local wall pressure, static temperature);
  s.gamma_chamber = the chamber's frozen gamma (chamber Mach, acoustic sound speed, tap-off
  drive gas). The turbine-exhaust injection static reads the table's pe/pc directly.
Re-solved calibrations (each is DEFINED as a reverse-solve):
- BARTZ_ABS_FLUX_CALIBRATION["LOX/LH2"] 0.66 -> 0.693 (corpus RS-25 throat back to the cited
  118 MW/m2; it read 113.4 at 0.66 with the new c*).
- turbine_exhaust.EXHAUST_INJECTION_PRESSURE_RATIO 2.50 -> 2.19 (F-1 58 psia against the table's
  own eps-10 static, pe/pc 0.01362, instead of the one-gamma 0.0119).
Watched, not tuned:
- CHANNEL_DP_CALIBRATION 0.93: reference regen design jacket dP 1.535 -> 1.523 MPa (-0.8 %;
  its comment's target is "~1.6 MPa"). Left.
- ETA_CSTAR_CEILING 0.99: now binds only for injector multipliers >= ~1.016 (gas-centered
  swirl, quintuplet, platelet) on top of 0.975. Left; validate 27/27.
- All validate banners 27/27 (spot checks exact on their anchors, integration checks within
  0.4 %, GG-bleed, cycle bands, turbine-exhaust, cooling all pass).
Found on the way (separate commits): the tables now also carry pe_over_pc_by_eps
